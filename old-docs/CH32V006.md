# FiveForths on the WCH CH32V006 (QingKe V2C, RV32EC)

This branch ports [FiveForths](https://github.com/aw/fiveforths) from the
GD32VF103 (Longan Nano) to the WCH CH32V006F8U6 (62 KiB flash, 8 KiB SRAM),
and extends it with an eForth-style kernel word set. Everything below was
verified both in a cycle-exact RV32EC emulator and on real silicon over a
WCH-LinkE.

## Status

Working on hardware: interactive interpreter at a true 115200 baud, numbers
(decimal and 0x-hex), all 19 upstream primitives, 26 new primitives, colon
definitions, IMMEDIATE user words, `begin`/`until` loops written in Forth,
backspace/DEL line editing, and a forensic trap handler that prints
`T<mcause> <mepc>` instead of silently misbehaving.

Departure from upstream: word headers are now jonesforth-style counted
strings instead of djb2 hashes (link cell, flags+length byte with
F_IMMEDIATE=0x80 / F_HIDDEN=0x20 / 5 length bits, the name itself, zero
padding to a cell boundary, code field). Names are limited to 31 chars,
`words` lists the dictionary, and `find` compares actual names, so hash
collisions are gone and headers are self-describing on-device and in dumps.
`djb2.c` and the `make djb2` target are deleted; upstream's HOWTO.md and
REFERENCE.md describe the old hashed headers and no longer apply here.

## Hardware setup

- WCH-LinkE to target: SWDIO/SDI -> PD1, 3V3, GND
- Serial console through the LinkE UART passthrough: LinkE RX <- PD5 (USART1
  TX), LinkE TX -> PD6 (USART1 RX)
- Clock: HSI 24 MHz, AHB /1, one flash wait state, BRR 208 (115384 baud,
  +0.16 %)

## Build / flash / talk

    make build                # binutils >= 2.39 (rv32ec_zicsr_zmmul)
    make flash-ch32v006       # minichlink -w fiveforths.bin flash -b
    make term                 # picocom -b 115200 --omap crcrlf --imap lfcrlf

Never leave `minichlink -r` as the last debugger command: it halts the core
and does not resume it; follow with `minichlink -b`.

## What the port actually required (the six silicon lessons)

| # | Problem | Fix |
|---|---------|-----|
| 1 | RV32E has only x0-x15; upstream uses t3-t6/s2/s3 | Injective remap (s2->s0 as RSP, t3->a4, t4->a5, t5->gp, t6->tp), s3 eliminated by spilling ra to the return stack |
| 2 | QingKe executes from the 0x00000000 flash alias | Link at 0x00000000 (PC-relative `la` of RAM symbols breaks otherwise); also RSP must be live before the boot banner (the spill added a boot-order dependency) |
| 3 | CH32V006 resets with a /2 AHB prescaler hidden in CFGR0 | Full write CFGR0 = 0, not a HPRE-only read-modify-write |
| 4 | CH32V00x needs 1 flash wait state above 15 MHz (unlike CH32V003) | FLASH_ACTLR = 1 before raising HCLK to 24 MHz; without it the chip reset-loops |
| 5 | QingKe V2 traps on misaligned `lw` (Bumblebee performs them) | `.balign CELL` before the inline `.loop`/`.dloop` data words |
| 6 | QingKe V2 traps on misaligned `lhu` too | The "0x" prefix check in `number` now uses two `lbu` instead of one `lhu` at arbitrary TIB offsets |

Plus: the QingKe trap vector base masks low mtvec bits, so before the handler
was 1 KiB-aligned every trap vectored to 0x000 = `_start` and looked like a
spontaneous reboot. The handler is now an aligned forensic beacon.

## New primitives (src/11-eforth-primitives.s)

Stack: `drop dup swap over sp! rp!` - Return stack: `>r r> r@` -
Bytes: `c@ c!` - Logic: `and or xor invert 0<` - Arithmetic: `um+ -` -
Inner interpreter: `execute branch 0branch ,` - Defining: `immediate '` -
Dictionary: `>cfa words`

Conventions: truth flags are -1; `here` and `latest` push variable
*addresses* (use `@`); compiled cells hold code-field addresses. With the
jonesforth headers, `'` returns the code field address directly and
`execute` consumes one, so user code never does header arithmetic: the old
`8 +` idiom is gone. `latest @` still gives a *header* address; convert it
with `>cfa` (e.g. `latest @ >cfa execute` runs the newest word).

Assembler note: `defcode` computes the name length itself (`9f - 8f` around
the `.ascii`), and re-quotes the macro argument (`.ascii "\name"`) because
GAS strips the quotes that call sites pass. Immediate primitives pass
F_IMMEDIATE as the new fourth argument (`;` and `'` do).

## Session cookbook (RAM definitions vanish on reset)

    : . 48 + emit ;                         \ single-digit print
    : begin here @ ; immediate
    : until ' 0branch , , ; immediate
    : cnt 9 begin dup . 1 - dup 0= until drop ;
    cnt                                     \ prints 987654321
    ' cnt execute                           \ same, via tick
    latest @ >cfa execute                   \ same, via the dictionary
    words                                   \ list every visible word

## Debugging infrastructure that exists and is worth keeping

- `rv32emu.py` (conversation artifact, not in-tree): RV32EC+Zmmul emulator
  that traps on misaligned 16/32-bit access like the silicon; it reproduced
  every hardware failure except the two alignment traps it was then taught
  to catch. Feed it a session string, get the UART transcript.
- The beacon: any trap prints `T<mcause> <mepc>` on the console and hangs
  with state intact for gdb (`minichlink -G` + `gdb-multiarch`).
